# gnmi_cli_lib_verifying

Verification suite for gnmi_cli_lib. This package contains the generated test harness, data, and reporting utilities used to validate converter output against gNMI JSON across real devices.

## Purpose

- Execute per-command verification tests against captured gNMI/CLI pairs
- Generate consolidated analysis reports (ALL_COMMANDS_ANALYSIS.md)
- Support rebuilding and merging test data

## Requirements

- Python 3.8+
- gnmi_cli_lib available in the workspace or Python path

## Quick Start

### Run all verification tests

```bash
python run_all_tests.py
```

### Generate the consolidated report

```bash
python generate_all_commands_analysis.py
```

### Run a single command test

```bash
python test_53_show_queue_counters.py
```

## Data Layout

- test_data/ contains per-command JSON + CLI fixtures
- test_*.py files are auto-generated per command
- ALL_COMMANDS_ANALYSIS.md is a generated report and kept for reference

## Notes

- verification_report.md is generated by runs and can be ignored in source control
- Use generate_test_files.py after modifying command coverage or adding new datasets
